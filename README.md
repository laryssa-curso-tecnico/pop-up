# Pop-ups

Uma página com diferentes exemplos de pop-ups e elementos interativos, demonstrando diferentes formas de exibir informações e interações para o usuário.

## Funcionalidades

- Modal pop-up
- Alertas
- Tooltip
- Notificações
- Lightbox
- Menu de contexto
- Caixa de confirmação
- Entrada de texto

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
